## 一、这篇文章想做什么

机制可解释性（mechanistic interpretability）的目标，是像逆向工程一个编译后的程序那样，把神经网络的权重“反编译”成人能读懂的算法。卷积网络上已经有不少这样的工作，但 Transformer 结构不同，需要一套新的“看法”。

这篇文章的策略是**先从最简单的模型下手**：

- 只研究 **attention-only** 的 Transformer，去掉 MLP 层；
- 忽略偏置项和 LayerNorm 等细节（或把它们看作可以折叠进权重的东西）；
- 依次分析 **0 层、1 层、2 层** 模型。

作者并不声称这些小模型本身有多大用处，而是想建立一套数学语言，让我们能把模型的行为拆解成可以逐项检查的“电路”。这套语言后来成为 Anthropic 一系列可解释性工作（induction head、superposition 等）的基础。

## 二、换一个角度看 Transformer

### 2.1 残差流是“通信总线”

传统画法把 Transformer 画成一层层串联的模块。文章建议换一种理解：**残差流（residual stream）才是主角**。

- 每一层（注意力头、MLP）都从残差流中**读**取信息（一次线性投影），计算后再把结果**加**回残差流（又一次线性投影）。
- 残差流本身不做任何计算，只做加法，因此是一个**线性、可叠加**的通道。

这带来两个直接的推论：

1. **任意两层之间都存在“直连”**。第 1 层写入的东西，第 3 层可以直接读到，不必经过第 2 层。于是可以把“第 1 层的输出矩阵”和“第 3 层的输入矩阵”相乘，得到一个**虚拟权重（virtual weight）**，描述它们之间的直接交流，例如 $W_I^{2}\,W_O^{1}$。
2. **残差流是带宽瓶颈**。残差流的维度 $d_\text{model}$ 往往远小于所有层读写维度之和，各层只能在有限的子空间里“分时共享”。文章推测，部分注意力头和神经元的作用就是“清理内存”，把不再需要的信息从残差流里擦掉。

另外，残差流**没有特权基底（privileged basis）**：对残差流做任意旋转，同时相应地旋转读写它的矩阵，模型的行为完全不变。所以直接盯着残差流的某一维看通常没有意义。相比之下，注意力模式（经过 softmax）和 MLP 神经元（经过逐元素非线性）的坐标是有意义的。

### 2.2 注意力头彼此独立、可加

通常的实现会把多个头的输出拼接（concat）后再乘一个输出矩阵 $W_O$。但把 $W_O$ 按头切块后可以看出，这等价于**每个头各自乘上自己的那块 $W_O^h$，再把结果相加**。

所以多头注意力可以看成**若干个独立的头并行地往残差流里写东西**，这是后面“按头拆解”的前提。

### 2.3 一个注意力头 = 两个几乎独立的计算

记 token 位置之间的注意力模式为 $A^h$（一个“位置 × 位置”的矩阵），文章把单个头写成张量积形式：

$$
\begin{aligned}
h(x) &= \left(A^h \otimes W_O^h W_V^h\right) x \\
A^h &= \operatorname{softmax}^*\!\left(x^{\top} W_Q^{h\top} W_K^{h}\, x\right)
\end{aligned}
$$

其中 $\operatorname{softmax}^*$ 表示带自回归掩码的 softmax。张量积 $A \otimes W$ 的含义是：$A$ 负责在**位置之间**搬运信息，$W$ 负责对**每个位置的向量**做线性变换，两者互不干扰。

由此自然引出两个矩阵：

| 名称 | 定义 | 作用 |
| --- | --- | --- |
| **QK 电路** | $W_{QK}^h = W_Q^{h\top} W_K^h$ | 决定“从哪里读”：哪个 query token 关注哪个 key token |
| **OV 电路** | $W_{OV}^h = W_O^h W_V^h$ | 决定“读到后写什么”：被关注的 token 会对输出产生什么影响 |

要点：

- $W_Q$ 和 $W_K$ 只以乘积形式出现，$W_O$ 和 $W_V$ 也是。单独解释其中某一个矩阵没有意义，因为可以在它们之间插入任意可逆变换而不改变模型。
- 这两个矩阵都是 $d_\text{model} \times d_\text{model}$ 的，但秩不超过 $d_\text{head}$，是**低秩**的。
- 一旦**固定注意力模式**，整个头就是关于输入的**线性**映射。这是后面所有“路径展开”分析的关键技巧。

## 三、零层 Transformer：只会二元语法

没有任何注意力层时，模型只剩下嵌入和反嵌入：

$$
T = W_U W_E
$$

每个位置只能看到当前 token，于是 $W_U W_E$ 最多只能学到“给定当前 token，下一个 token 是什么”，也就是**二元语法（bigram）统计**。这个看似平凡的结果很重要：在更深的模型里，这一项作为**直接路径**一直存在。

## 四、单层 attention-only Transformer

### 4.1 路径展开

把单层模型的前向过程展开，可以把输出 logits 写成若干项之和：

$$
T = \underbrace{\mathrm{Id} \otimes W_U W_E}_{\text{直接路径}}
+ \sum_{h} \underbrace{A^h \otimes \left(W_U W_{OV}^h W_E\right)}_{\text{经过第 } h \text{ 个头的路径}}
$$

- 第一项就是零层模型的 bigram；
- 后面每一项对应一个注意力头。

把嵌入和反嵌入“乘进去”后，每个头可以用两个**词表 × 词表**的大矩阵完整描述：

- **QK 电路**：$W_E^{\top} W_{QK}^h W_E$，第 $(i, j)$ 项表示当前 token 是 $i$ 时，有多想关注之前出现过的 token $j$；
- **OV 电路**：$W_U W_{OV}^h W_E$，第 $(k, j)$ 项表示如果关注到了 token $j$，会把下一个 token 是 $k$ 的 logit 推高多少。

这两张表可以直接查看，**不需要任何输入数据**就能读出这个头“在做什么”。这是全文最漂亮的地方之一。

### 4.2 skip-trigram：单层模型的“算法”

结合 QK 和 OV，单层模型的每个头大致实现了这样的规则：

> 当前 token 是 **B**，上文某处出现过 **A** → 提高下一个 token 是 **C** 的概率。

文章把它称为 **skip-trigram**，写作 `[A] … [B] → [C]`（A 和 B 之间可以隔着任意多个 token）。其中：

- “B 看向 A”由 QK 电路决定；
- “看到 A 后推高 C”由 OV 电路决定。

一类非常常见的 skip-trigram 是 **C = A**，也就是“上文出现过的词，后面更容易再次出现”。这就是**复制（copying）**行为。很多单层头都在做某种形式的复制，例如在代码中复用变量名、在文本中重复人名。

### 4.3 因式分解带来的“bug”

因为 QK 和 OV 是**分开**的两张表，模型没法表达“只有当 B 关注的是 A₁ 时才输出 C₁，关注 A₂ 时才输出 C₂”这种精确的配对。如果同一个头既想学 `A₁ … B → C₁`，又想学 `A₂ … B → C₂`，它也会不可避免地给 `A₁ … B → C₂` 这种错误组合加分。

这是单层注意力在表达能力上的一个结构性局限，也给了更深的模型“组合”的动机。

### 4.4 用特征值检测复制

如何不看具体 token 就判断一个头是不是在复制？文章给出的办法是看 **OV 电路的特征值**：

- 如果矩阵把某个 token 映射回它自己（或相近的 token），对应的特征值往往是**大的正数**；
- 因此，一个头的 OV 电路如果**正特征值占主导**，它多半在做复制。

文章统计发现，单层模型中相当多的头 OV 特征值以正为主。同样的思路也可以用在 QK 电路上，检测“相同 token 互相关注”的倾向。用特征值或奇异值来“概括”一个巨大矩阵，是这篇文章反复使用的工具。

## 五、两层 attention-only Transformer

### 5.1 注意力头之间的三种组合

到了两层，第二层的头可以读取第一层头写进残差流的东西。根据读取发生在哪个输入上，文章把这种交互分成三类：

| 组合方式 | 第一层头的输出被用在 | 效果 |
| --- | --- | --- |
| **Q-composition** | 第二层头的 query | 改变“我要找什么” |
| **K-composition** | 第二层头的 key | 改变“我能被怎样找到” |
| **V-composition** | 第二层头的 value | 改变“被读到后写出什么” |

其中 Q、K 组合影响的是**注意力模式**，V 组合影响的是**写出的内容**。

为了度量组合的强度，文章定义了一个简单的分数：两个矩阵乘积的 Frobenius 范数，除以各自范数的乘积。以 K-composition 为例：

$$
\frac{\left\lVert W_{QK}^{h_2}\, W_{OV}^{h_1} \right\rVert_F}{\left\lVert W_{QK}^{h_2} \right\rVert_F \left\lVert W_{OV}^{h_1} \right\rVert_F}
$$

分数越高，说明第一层头写的东西越多地落在第二层头读取的子空间里。

### 5.2 路径展开与虚拟注意力头

两层模型的 logits 同样可以展开：

$$
\begin{aligned}
T = {} & \mathrm{Id} \otimes W_U W_E \\
& + \sum_{h} A^h \otimes \left(W_U W_{OV}^h W_E\right) \\
& + \sum_{h_2,\, h_1} \left(A^{h_2} A^{h_1}\right) \otimes \left(W_U W_{OV}^{h_2} W_{OV}^{h_1} W_E\right)
\end{aligned}
$$

最后一项称为**虚拟注意力头（virtual attention head）**：两个头串联，注意力模式是 $A^{h_2} A^{h_1}$，OV 电路是 $W_{OV}^{h_2} W_{OV}^{h_1}$，这正是 V-composition。

一个需要注意的细节是：如果存在 Q 或 K 组合，$A^{h_2}$ 本身就依赖第一层头的输出，上面的式子就不再是简单的线性展开。所以作者把分析拆成两部分：OV 路径（输出写什么）与 QK 路径（注意力模式怎么来）。

实验上，作者发现两层模型中**虚拟注意力头的贡献很小**，而 **K-composition 非常显著**。这就把目光引向了全文最重要的发现。

### 5.3 induction head

两层模型里出现了一种由两个头协作完成的电路，称为 **induction head**。它实现的算法是：

> 如果上文出现过 `[A][B]`，现在又遇到了 `[A]`，那么预测下一个 token 是 `[B]`。

实现方式大致如下：

1. **第一层：previous-token head**。这个头在每个位置都关注**前一个** token，并把“我的前一个 token 是什么”写进当前位置的残差流。于是在 `[B]` 的位置上，会多出一条信息：“我前面是 A”。
2. **第二层：induction head（K-composition）**。当前 token 是 `[A]`，它的 query 去寻找“前一个 token 是 A”的位置。因为 key 中带有第一层写入的信息，它会精准地找到之前 `[B]` 的位置。
3. **复制**。找到 `[B]` 后，induction head 的 OV 电路做复制，把 `[B]` 的 logit 推高。

和单层的 skip-trigram 相比，induction head 的关键优势在于：

- 它**不依赖具体的 token 统计**，而是一种“看到重复模式就续写”的通用算法；
- 即使在**完全随机的 token 序列**上，只要序列重复第二遍，模型也能准确预测后半段，而单层模型做不到。

这意味着两层模型已经具备了一种初步的**上下文学习（in-context learning）**能力。作者在后续论文中进一步论证，induction head 可能是大模型上下文学习能力的重要机制来源。

## 六、文章的方法论遗产

抛开具体结论，我认为这篇文章留下了几件可以反复使用的“工具”：

1. **残差流视角**：把模型看成许多组件在共享通道上读写，而不是一摞串联的层。
2. **QK / OV 分解**：把注意力头拆成“去哪读”和“写什么”两件几乎独立的事。
3. **固定注意力模式后做路径展开**：把非线性的模型局部线性化，逐项分析每条路径的贡献。
4. **用特征值、奇异值、组合分数概括大矩阵**：不需要逐个 token 检查，也能对一个头的性质下判断。
5. **从玩具模型开始**：先在能完全理解的小模型上建立概念，再迁移到大模型上验证。

## 七、局限与后续

文章自己也明确承认了不少局限：

- **没有处理 MLP 层**。真实 Transformer 中约三分之二的参数在 MLP 里，而 MLP 的神经元常常同时编码多个不相关的特征（多义性），很难用本文的线性工具直接分析。
- **超位置（superposition）**。残差流和神经元可能用远多于维度数的“特征”叠加存储信息，这是后来 *Toy Models of Superposition* 等工作的主题。
- **规模问题**。词表 × 词表的电路矩阵在大模型中非常庞大，层数加深后路径数量也会指数增长，需要更好的概括方法。

推荐的延伸阅读：

- *In-context Learning and Induction Heads*（Olsson 等，2022）：在更大的模型中研究 induction head 与上下文学习的关系；
- *Toy Models of Superposition*（Elhage 等，2022）：研究特征如何叠加存储；
- 以及 Transformer Circuits Thread 上的后续文章。

## 八、个人小结

读完这篇文章，最大的收获是一种“拆开看”的思路：Transformer 不再是一个难以理解的黑箱，至少在小模型里，可以被拆成**直接路径 + 若干注意力头 + 少量头之间的组合**，而每一部分都能用一两张矩阵表来描述。

induction head 的发现尤其有启发性。它说明哪怕只有两层注意力，模型也会自发学出一种通用的、与具体内容无关的算法；而这类算法，可能正是大模型很多“智能”行为的雏形。

如果你想动手复现，可以用 [TransformerLens](https://github.com/TransformerLensOrg/TransformerLens) 加载一个小模型，画出各个头的注意力模式，并在一段重复的随机 token 序列上找找 previous-token head 和 induction head。
